# 拾页 Snapline 使用指南

## 网页版先看这里

访问 [公开网页版](https://jokerlixing.github.io/snapline-chrome-extension/)，导入 HTML 文件或整个资源文件夹，也可以粘贴 HTML 代码，生成预览后导出图片/PDF。无需安装和登录。网页版支持宽度预设、自定义宽度、重置和本机历史。

网页版不执行导入网页的脚本；跨站网站、登录页面、复杂动态布局请使用插件。页面中引用的跨域资源可能无法渲染，导入完整资源文件夹可改善结果。下方标签页捕获、Chrome 权限和安装步骤属于插件版；格式与设置说明适用于两者。

## 第一次安装

适用于 Chrome 120 及以上版本。

1. 从 [GitHub Releases](https://github.com/jokerlixing/snapline-chrome-extension/releases/latest) 下载 `Snapline-v1.2.2.zip`，先完整解压；本机构建的压缩包名为 `拾页-Snapline-v1.2.2.zip`。从源码构建时使用 `dist/snapline` 文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，按 Enter。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**。
5. 选择包含 `manifest.json` 的扩展文件夹，然后确认。
6. 点击浏览器右上角的拼图图标，在拾页旁点击固定图标。之后可以直接从工具栏打开工作台。

请保留加载的文件夹。移动或删除它，Chrome 可能无法继续运行扩展。更新扩展文件后，在扩展管理页点击拾页卡片的刷新按钮，再刷新工作台。

安装方式依据 [Chrome 官方说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。如果电脑由公司或学校统一管理，能否加载本地扩展取决于管理员设置。

## 保存正在浏览的网页

1. 先在 Chrome 打开需要保存的网页，完成登录，并让页面加载好。
2. 点击工具栏中的拾页图标。
3. 在工作台选择 **浏览器标签页**，确认标签页列表里选中了目标网页。
4. 选择 PNG、JPG、WebP 或 PDF，设置截取范围和清晰度。
5. 开始生成，等待预览出现，再保存到电脑。

工作台与网页是不同的标签页。选错页面时，重新选择目标标签页即可。截取期间请让原网页保持打开，避免刷新、跳转或同时开启另一次截图。

保存 ChatGPT 等需要登录的长对话时，先在目标标签页打开对话，等待回答结束，再选择 **完整网页 · 包含滚动区域**。拾页会尝试识别正文所在的主滚动区域，逐段截图并拼接到末尾；生成后恢复原来的滚动位置。识别到主区域时，结果聚焦该区域正文，不包含区域外的侧栏、输入框等工具栏。PNG、JPG、WebP 和 PDF 都使用同一份完整截图。已验证同类固定视口、内部滚动与虚拟列表夹具，不保证每个网站的特殊布局均兼容，也未将私人登录会话列为已实测网站。

点击来源标题旁的 **重置网页来源**，会同时清空已导入的文件、网址或标签页选择、当前预览及缩放状态，回到待选择页面的状态。当前来源类型、导出设置和历史预览记录会保留。

生成过程中，按钮会变为 **取消生成**。需要停止时点击它，等待“正在取消…”结束，拾页会清理临时页面并恢复原页面的捕获设置。已有的历史记录不会因此删除。取消生成适用于截图阶段；导出后若不想保存文件，可以在 Chrome 保存对话框中取消。

## 保存网页链接

1. 选择 **网页链接**。
2. 粘贴完整地址，例如 `https://example.com`。
3. 设置导出格式和范围，开始生成。

拾页会在浏览器中打开地址并捕获页面。需要登录的网站，建议先自行打开并登录，再通过「浏览器标签页」保存。对于加载较慢的页面，可以增加等待时间；页面持续加载、需要点击后才出现的内容，建议先手动展开。

## 导出本地 HTML

### 只有一个 HTML 文件

选择 **本地 HTML**，导入 `.html` 或 `.htm` 文件。把图片和样式都写在文件内部的静态 HTML，最适合这样导入。插件版也能在隔离页面中运行内联脚本；网页版不会执行导入脚本。

单独选择 HTML 文件不会同时读取旁边的图片或 CSS。如果出现图片丢失、排版不对，请改为导入整个文件夹。

### HTML 旁边还有图片、CSS 等文件

选择导入文件夹，把 HTML 与相关资源所在的目录一起导入，然后选择入口 HTML，例如 `index.html`。保持原来的目录结构，例如：

```text
我的网页/
  index.html
  styles/
    main.css
  images/
    cover.png
```

文件夹导入适合普通静态 HTML 及常见的相对路径图片、样式；相对路径脚本只在插件版运行。单次所选文件总大小上限为 **25 MB**，打包后的 HTML 和资源最多 **60 MB**；请选择网页实际需要的文件夹，避免包含视频、依赖目录或其他无关文件。插件版不会递归打包内嵌子页面的相对资源；网页版会略过 iframe、object 等嵌入内容。

依赖 JavaScript 模块导入、动态 `fetch()`、服务端接口或路由的项目，建议先启动项目自己的本地服务器，在 Chrome 打开 `http://localhost:端口`，再用「浏览器标签页」或「网页链接」捕获。

### 已经用 Chrome 打开了本地 HTML

如果地址栏是 `file:///...`，也可以通过「浏览器标签页」捕获。需要先在 `chrome://extensions` 中打开拾页的 **详细信息**，开启 **允许访问文件网址**，再重试。此开关是 Chrome 对本地文件的额外权限控制，参见 [官方权限说明](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions#allow-access)。

## 怎么选导出格式

| 格式 | 适合什么 | 提示 |
| --- | --- | --- |
| PNG | 界面截图、文字内容、需要透明区域的图片 | 细节清晰，文件可能较大 |
| JPG | 照片较多的页面、方便聊天分享 | 调低质量可减小文件；不支持透明 |
| WebP | 兼顾体积和画质的网页图片 | 可调整质量，也支持透明区域 |
| PDF | 保存资料、打印、按纸张分页 | 内容是截图，文字不可选中或搜索 |

PDF 的 **A4 分页** 和 **Letter 分页** 会把长截图按纸张高度连续切开，适合打印。分页依据图像位置，可能切到段落或图片；它不会像文档排版工具那样自动避开内容。**单张长页** 把内容放入一张长 PDF 页面，适合在屏幕上连续查看。

WebP 的任意一边最多支持 16,383 像素，超过时拾页会等比例缩小整张图片，并在预览下方提示导出尺寸，避免截掉底部内容。需要保留超长图片的原始像素时，可选 PNG、JPG 或分页 PDF。所有格式都必须先满足下面的截图生成上限，WebP 缩小并不代表能处理任意长度的网页。尺寸限制见 [WebP 官方说明](https://developers.google.com/speed/webp/faq#what_is_the_maximum_size_a_webp_image_can_be)。

## 把结果调清楚、调合适

| 设置 | 使用建议 |
| --- | --- |
| 完整网页 · 包含滚动区域 | 保存长页或符合识别条件的正文主滚动区域；网页版仅处理静态内容 |
| 当前可见区域 | 插件保存目标页面当前视口；网页版保存导入页面顶部的一屏，滚动工作台不会改变截图起点 |
| 保持原始宽度 | 插件保留目标标签页宽度，新建捕获页使用浏览器窗口宽度；网页版使用工作台当前窗口宽度 |
| 1440 / 768 / 390 像素 | 查看桌面、平板、手机尺寸下的网页布局 |
| 自定义宽度 | 选择后输入 200–7680 之间的整数像素，再生成预览 |
| 1 倍 / 2 倍 / 3 倍 | 倍数越高，输出像素越多，文件和内存占用也越大 |
| JPG / WebP 质量 | 30–100%，在文件体积与细节之间调整；PNG 和 PDF 不使用此设置 |
| 透明背景 | 保留页面已有的透明区域；不能抠除白底或其他已设置的背景色 |
| 加载滚动后出现的图片 | 插件尝试滚动以触发加载；网页版仅尝试加载原生懒加载图片，不运行脚本或触发脚本动态加载 |
| 加载后再等待 | 界面可选 0.5 / 1.5 / 3 / 5 秒，给可用的图片和字体等更多时间；网页版不会因此执行脚本 |

固定宽度会让支持响应式设计的网页重新排版；390 像素宽并不等同于一台真实手机，不会模拟触屏、移动系统或手机浏览器。输入宽度是排版宽度，页面固定宽布局溢出或截取正文主区域时，最终图片宽度可能不同。提高倍数也无法补回原图本来没有的细节。

截图生成上限为单边 **32,760 像素**、总像素 **6,400 万**，包含清晰度倍数。浏览器一次只能合成约 **16,384 设备像素** 的画面，超过这个范围的整页或高清晰度截图会先分段截取再拼接，因此长网页和 2–3 倍清晰度同样能完整导出，只是生成时间略长；不需要为此调整设置。PDF 支持 0/10/20 mm 页边距，单张长页高度最多 **5,080 mm**；A4/Letter 分页 PDF 最多 **250 页**。超限会提示调整设置，内存较少的设备可能在达到这些上限前失败。

修改自定义宽度后，需要重新生成预览才会应用。数值和模式会自动记住；从历史记录打开结果时，也会恢复该次截图的宽度设置。

如果覆盖新版文件后只刷新工作台，Chrome 可能还在运行旧版截图程序。生成自定义宽度预览时，若收到旧版“请选择原始宽度、手机、平板或桌面尺寸”提示，拾页会重新加载扩展，恢复来源和设置后继续生成。自动恢复最多尝试一次；若后台仍是旧版，请在扩展管理页确认加载的是新版文件夹，并刷新拾页卡片。

## 最近的网页

工作台在本地保留最近 **12 次生成成功的预览**，无需先下载，便于预览和再次导出。可以删除单条记录，也可以清空全部记录。删除工作台记录不会删除已经保存到电脑的下载文件。

网页版将偏好和记录保存在当前网站的浏览器存储中；插件版保存在 Chrome 扩展存储中，两版互不共享。关闭工作台不会自动清空记录；清除网站数据或卸载扩展会移除对应记录，电脑上的下载文件需自行管理。

## 常见问题

**为什么顶部出现“正在调试此浏览器”之类的提示？**

拾页使用 Chrome 的页面捕获能力生成图片，因此捕获期间 Chrome 会显示调试提示。完成或失败后，拾页会断开连接。如果手动关闭提示，当前捕获可能被中断。详情可见 [Chrome debugger API 文档](https://developer.chrome.com/docs/extensions/reference/api/debugger)。

**提示无法捕获这个页面。**

`chrome://` 等浏览器内部页面、Chrome 应用商店及其他受保护页面受到浏览器限制。请选择普通网站、本地服务页面，或导入 HTML 文件。若正在打开目标页的开发者工具或其他截图扩展正在操作它，先结束这些操作再重试。

**图片还没加载完，或网页截图缺少内容。**

插件版可增加等待时间、开启懒加载处理；也可以先返回原网页向下滚动，确认内容出现后再捕获。完整网页会尝试处理占据页面主要空间的一个内部滚动区域，小型代码框、侧栏、多个独立面板不会逐个展开。无限滚动页面不会无限采集；需要点击按钮、登录或展开折叠区的内容，请先手动操作。若截图过程中正文长度仍变化，会提示等待页面稳定后重试。网页版遇到脚本加载内容时，请改用插件；静态资源缺失时请导入完整资源文件夹。

**本地 HTML 导入后样式或图片丢失。**

优先使用文件夹导入，并确认所有相对路径资源都在所选文件夹内。在线资源需要联网。如果是通过模块、接口或构建工具运行的网页，启动本地服务器后再捕获。

**长页面或 3 倍清晰度导出失败。**

较大图片需要更多内存，浏览器也对图像尺寸有限制。先降低到 1 倍，或改为当前可见区域。单张长页 PDF 也有尺寸限制；需要打印时优先选择 A4 或 Letter 分页。

**PDF 为什么不能复制文字？**

拾页生成的是截图 PDF，保留页面画面，不包含可搜索的文字层。如果需要可选中文字的 PDF，可以使用网页本身的导出功能，或 Chrome 的打印功能「另存为 PDF」；结果排版可能与页面截图不同。

**在哪里找到导出的文件？**

两版都默认使用网页标题作为文件名，工作台没有文件名输入框。插件版会请求浏览器保存窗口，可以修改文件名和位置。网页版通过普通浏览器下载，是否弹出保存窗口取决于浏览器设置；需要改名时开启下载前询问保存位置，或下载后重命名。

保存位置由 Chrome 下载设置决定。按 `Ctrl + J` 打开下载记录，可以找到文件并显示其所在文件夹。
