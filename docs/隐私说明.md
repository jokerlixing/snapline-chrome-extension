# 拾页 Snapline 隐私说明

版本：1.0.0

拾页在本机 Chrome 浏览器中处理页面、生成预览和导出文件。拾页没有账号系统、远程处理服务器、广告或使用行为统计，也不会主动把网页内容、本地文件、截图或 PDF 上传到服务器。

## 会读取哪些内容

- **标签页信息**：读取可选页面的标题和网址，让你选择要捕获的标签页。
- **目标网页画面**：仅在发起捕获时，读取所选页面的布局与画面，并按导出设置临时调整宽度、等待或滚动。操作结束后断开捕获连接。
- **你导入的文件**：处理你主动选择的 HTML 文件，或所选文件夹中的页面和资源，以便渲染并导出。
- **导出设置**：记住常用的格式、清晰度等选项，方便下次使用。

拾页不会在你没有发起捕获时持续录屏。网页地址和页面标题可能出现在本机的任务记录中，请按需删除包含敏感信息的记录。

## 权限为什么需要

| 权限 | 用途 |
| --- | --- |
| `debugger` | 使用 Chrome 的页面布局和截图接口，生成全页或当前可见区域截图，并调整捕获尺寸 |
| `tabs` | 获取可选择的标签页标题和网址，打开要捕获的链接 |
| `downloads` | 把你生成的图片或 PDF 保存到电脑 |
| `storage` | 在浏览器本地保存导出偏好 |

捕获期间，Chrome 可能显示调试提示。这是浏览器提供的可见提示；捕获完成或失败后，拾页会断开连接。你也可以通过 Chrome 的提示中断正在进行的捕获。权限含义可查阅 [Chrome 权限列表](https://developer.chrome.com/docs/extensions/reference/permissions-list) 和 [debugger API 文档](https://developer.chrome.com/docs/extensions/reference/api/debugger)。

如果通过「浏览器标签页」捕获 `file://` 本地标签页，需要自行在扩展详细信息中开启 **允许访问文件网址**。文件选择器和文件夹导入只读取你主动选择的内容。

## 数据保存在哪里

- 导出偏好保存在当前 Chrome 用户配置的扩展本地存储中。
- 最近 **12 次**捕获结果保存在该扩展的本地 IndexedDB 中，用于预览与再次下载。
- 导入的 HTML 及打包资源也会暂存在扩展本地数据库，用于生成预览。
- 你下载的文件保存在 Chrome 的下载目录或你选择的位置。

可以在工作台中删除单条记录或清空全部记录。清除工作台记录不会删除已下载的文件；已经下载的图片和 PDF 需要在电脑中自行删除。卸载扩展会移除扩展在该 Chrome 配置中的本地数据。

## 网页本身的联网行为

“本地处理”指拾页不将内容交给远程服务进行转换。在线网页仍会正常访问其网站；导入的 HTML 若引用网络图片、字体、样式或脚本，也可能连接原网站或第三方服务器。页面自己的脚本和请求遵循浏览器的运行规则，这些连接并不是拾页的上传或统计服务。

如需完全离线使用，请准备资源完整、无需联网的本地 HTML 或文件夹，并在断网环境中导出。含登录状态的页面，其截图可能包含你当前能看到的个人内容；导出后的文件由你决定保存和分享方式。
