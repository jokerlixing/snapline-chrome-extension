# 网页版与插件版

提供同一套工作台的两个运行环境：网页版通过 GitHub Pages 公开访问，插件版保留 Chrome 原生网页截图能力。公开现有 GitHub 仓库，采用 MIT 许可证，根目录提供使用说明。

网页版直接处理本地 HTML、完整资源文件夹和粘贴的 HTML，提供自定义宽度、图片/PDF 导出、重置和本机历史。导入文档放在禁止脚本执行的 sandbox iframe 中，同源权限仅供可信的渲染器读取文档；导入内容不插入主工作台 DOM。渲染克隆也继承禁止脚本执行的限制，避免导入脚本读取工作台数据。取消或失败移除隔离容器。

纯静态站点无法绕过浏览器同源限制读取其他网站或登录会话。网页版清晰引导这些来源使用插件，不把不能工作的 URL 输入作为可用截图功能。复杂 CSS、跨域媒体及浏览器专属内容的渲染以实际兼容范围为准。

构建分别产出 dist/site 和 dist/snapline。GitHub Actions 检查并构建站点，通过 GitHub Pages 官方部署操作发布 dist/site。静态资产使用相对路径，兼容仓库子路径。发布前核查 Git 历史中是否有不应公开的资料，之后验证公开仓库、Pages HTTPS 链接和在线真实导出。
