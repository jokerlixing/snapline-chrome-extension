# 1.1.0 预览与完整导出

目标是让用户输入自定义视口宽度、一键清空来源和预览，并完整保存正文位于内部滚动容器的网站。

自定义宽度在现有宽度选择器内增加入口，沿用现有生成预览流程，支持 200–7680 整数像素。校验同时位于工作台和捕获服务；偏好与历史记录保留数值。重置来源清理文件、网址、标签页选择及预览，保留导出设置和历史。异步文件及标签页读取使用版本标记，防止重置后旧结果回填。

普通文档继续使用浏览器整页截图。固定视口页面若存在主要内部滚动区域，则逐段滚动截图并拼接正文，避免单次扩大截图范围仍只得到容器当前可见内容。选择时排除小型代码框及导航栏；每段等待虚拟内容绘制，按实际 scrollTop 去除重叠。设置时间、尺寸和迭代上限，成功、失败、取消均恢复原网页状态。

JPG、WebP、PDF 使用同一份完整 PNG。WebP 超过格式尺寸时等比例缩小，并提示实际输出尺寸、核验解码尺寸；PDF 按完整图像连续切片。

验收覆盖普通长页、内部滚动、虚拟列表、自定义宽度、2 倍像素、全部导出格式的首中尾内容，以及重置竞态、取消和错误后恢复。私有对话采用同结构夹具，不复制会话内容到仓库。
