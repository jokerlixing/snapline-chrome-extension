欢迎使用拾页

1

安装到谷歌浏览器

打开 chrome://extensions，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择解压后的 snapline 文件夹。再把拾页固定到工具栏。

2

选一个你想留下的网页

在网页上点击拾页图标，或在工作台导入 HTML、选择整个文件夹、粘贴网址。有独立 CSS 或图片的本地网页，建议导入整个文件夹。

3

预览，然后导出

选好范围和清晰度，点击「生成预览」。满意后选择 PNG、JPG、WebP 或 PDF，点击「导出」即可。修改截图参数后，需要重新生成预览。

抓取期间 Chrome 会短暂显示调试提示，完成后自动结束。系统页面、扩展商店等受保护页面无法转换。动态应用建议先正常打开再选标签页；如页面使用懒加载，先手动浏览一遍效果更好。
